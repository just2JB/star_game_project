# 별의 정령 (Star Spirit)

원소로 성운을 조성하고 사출하는 도트 그래픽 우주 턴제 로그라이크.

- 기획 위키: https://claude.ai/artifact/4DLkJhJA5DNNAUkvVTj7Ke
- 기술: TypeScript + Phaser 3 + Vite

## 실행

```bash
npm install
npm run dev     # http://localhost:5173 에서 실행
npm test        # 규칙 테스트
npm run shot    # 스크린샷으로 화면 확인 (screenshots/)
```
